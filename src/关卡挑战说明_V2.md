# 仙家试炼 · 关卡挑战说明

> 「仙家试炼」入口：标题页 **🏯 仙家试炼** → 选择仙家 → 选择具体关卡。
> 本文档为关卡规则与游戏内玩家文案的唯一权威源，修改后同步至游戏即可。
> **仙家顺序与仙家图鉴一致**：按右侧星星（上手难度）升序排列——雷震子 → 邓婵玉 → 土行孙 → 哪吒 → 杨戬 → 苏妲己 → 云霄 → 姜尚。

## 一、通用规则

| 规则 | 说明 |
|------|------|
| 入口结构 | 仙家列表（头像）→ 该仙家的若干关卡（两级菜单） |
| 基础规则基准 | **所有仙家试炼均以正式对局规则为准**：双方开局各有 4 张手牌与 **10 灵气**；先手第 1 回合跳过整个收入阶段（不加灵气、不抽牌）；其余收入阶段灵气 +1、抽 1 张牌；灵气上限 15、手牌上限 7；回合流程、掷骰次数、凝神守御、闪避、状态与伤害结算均与正式对局一致。各关写明的初始气血即为该关气血上限。 |
| 第 3 关预设 | 每位仙家的第 3 关开局时，双方均为 **50 气血 / 10 灵气**，且**全部神通均已强化**；强化牌自对应牌库移除。**不限回合；第 15 回合起**，按该关写明的后续特殊规则提高难度。 |
| 例外申报 | 仅可通过本说明中逐条写明的**开局配置**、**定向牌**、**固定骰面 / 固定行动**、**胜负目标**或**不限时**改变体验；未写明即一律沿用正式对局规则。若新增设计与基础规则冲突，须先标注为关卡特殊规则，并在实现前确认。 |
| 挑战关卡不限时 | 不启用防御 4 秒自动守卫、回合倒计时或弹窗超时守卫 |
| 专属卡数量 | 每张仙家专属卡每关仅 1 张，除非该关特别说明例外 |
| 定向发牌 | 在玩家收入阶段从公共牌库取牌，牌库数量递减，牌不是无中生有；**定向牌替代当回合正常抽卡，不额外再抽 1 张**；神通自身写明“抽牌”时，定向牌替代该次神通抽牌 |
| 定向牌保护 | 某张唯一牌若会在未来回合定向发放，则在该回合到来前不会被正常抽到；到指定回合仍从公共牌库取出 |
| 胜负路由 | 达成胜利 → 通关弹窗 + 记录通关标记；失败 → 失败弹窗（看广告重开 / 返回） |
| 看广告 | 未通关关卡点击【开战📺】需看广告；挑战失败后重开也需看广告；已通关关卡点击【再次挑战】直接开始。 |
| 神通 | 挑战中神通效果正常发挥（抽卡/加状态等），战斗规则与正常模式一致 |
| 牌库 | 牌库内容与手册一致；若规则说明某神通已被强化，则牌库中去掉对应强化牌，牌库数量减少 |
| 改骰博弈 | **所有第 3 关从第 15 回合起**，玩家用【迷仙单引】/【双幡乱运】修改进攻方骰面时，对方重掷出一模一样的骰面，依然发动原神通；此前及非第 3 关、正式对局仍按正常改骰规则结算。 |
| 仙家解锁 | 当前解锁链：雷震子→杨戬，邓婵玉→苏妲己，土行孙→云霄，哪吒→姜尚；**必须完成来源仙家的全部 3 关，才会解锁对应仙家**。解锁方式可随仙家单独扩展 |
| 大关卡开放 | 仅正常模式中已解锁的仙家可进入其仙家试炼；锁定提示统一为“解锁 XX 仙家后，才可进入其试炼” |
| 小关卡开放 | 同一仙家的关卡按顺序开放：第 1 关 → 通关后解锁第 2 关 → 通关后解锁第 3 关 |
| 大关通关提示 | 第 3 小关通关且完成该仙家全部 3 关时，弹出“恭喜你已经完成【XX】试炼，现已解锁【XX】！” |
| 激励视频 | 未通关关卡点击【开战📺】需观看激励视频；通关后点击【再次挑战】直接开始；失败后点击重开仍需观看激励视频 |
| 玩家限制 | 玩家中[炫目]后尝试攻击必定投出 1-2，攻击落空。 |
| 玩家 / 对手 | 每关数值表以仙家名后的“（玩家）”“（对手）”标明双方身份；行动顺序同样标明先手身份。 |

## 三、雷震子试炼

---

### 第 1 关 · 仙杏续命

**设定**

| 项目 | 数值 |
|------|------|
| 雷震子（玩家） 气血 / 灵气 | 12 / 10 |
| 雷震子（玩家）开局持有手牌 | 4 张（其中包含【风雷仙杏+】） |
| 雷震子（玩家）开局生效 | 无 |
| 哪吒（对手） 气血 / 灵气 | 50 / 10 |
| 哪吒（对手）开局持有手牌 | 4 张（正常牌库随机抽取） |
| 哪吒（对手）开局生效 | 无 |
| 行动顺序 | 雷震子先手（玩家） |
| 胜利 | 雷震子存活 3 回合 |
| 失败 | 雷震子 气血归 0 |

**特殊规则**
1. 哪吒攻击阶段固定投掷 [2,3,4,5,6] 发动【九龙神火罩】。
2. 第 2 回合定向抽取【青面獠牙+】；首次投掷必定[1，2，6，6，6]，若发动【青面獠牙+】二次掷骰固定出现❤️，使其造成[不可防]伤害并回复气血。
3. 第 3 回合定向抽取【太乙还魂丹】；在主阶段使用，回复10点气血。
4. 雷震子的进攻回合，必定无法投出3个[6]，不论玩家是否使用重骰，一次最多出2个，如果玩家锁定了2个[6]，重骰必定不会出现[6]。
5. 玩家只有强化【风雷仙杏+】后，使用【风雷仙杏+】进行防御必定全是❤️，如果使用【风雷仙杏】进行防御，必定不出❤️
6. 第 1 个雷震子回合依正常先手规则跳过收入阶段；第 2、3 回合的定向牌分别替代正常抽牌。

**弹窗文案**

**开局**

⚠️ 仙杏续命：周营闲暇，二人相约陪练切磋。哪吒脚踏风火轮立于阵前，莲光环绕周身。雷震子欲以肉身硬抗哪吒 3 招。

胜利：雷震子存活 3 回合

失败：雷震子气血归 0

胜利提示：雷震子有很多强力回血神通。

**通关**

🏆 依仗自身恢复撑过几番交手，已然摸清哪吒莲花法相的防御路数。

**失败**

💀 一味依靠肉身硬拼，依旧抵不住莲火攻势，陪练暂且告一段落。（重新开始📺 / 返回挑战）
